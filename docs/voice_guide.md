# Studioza — Editorial Voice & Copy Guide

> *"Every page is a folio in an issue."*  
> The studio voice is that of a master printer and archivist: calm, specific, restrained, and slightly literary. It avoids all commercial photography hyperbole.

---

## 1. Core Principles

1. **Short declarative sentences.** State facts and observations. Avoid compound sentences that strain for enthusiasm.
2. **Zero exclamation marks.** Under no circumstances does copy in Studioza use `!`. Confidence does not shout.
3. **Banned vocabulary:**
   - *stunning*
   - *capture your special day*
   - *breathtaking*
   - *magic / magical*
   - *cherish forever*
   - *unforgettable*
   - *passionate*
   - *perfection*
   - *timeless memories*
4. **Physicality and craft.** Refer to images as *plates*, collections as *monographs* or *folios*, bookings as *commissions*, and the studio workspace as the *darkroom* or *desk*.
5. **Precise technical metadata.** Mention camera formats, film stocks (Kodak Tri-X, Portra 400, Ilford HP5), natural light angles, and geography directly without ornamentation.

## 2. Standard Interface Copy Catalog

### Empty States

| Context | Heading | Body / Subtext | Action / Link |
| :--- | :--- | :--- | :--- |
| **Archive / Portfolio** | No plates filed in this monograph. | The accession register contains no published images for this series yet. | Return to Monographs |
| **Stories / Journal** | The edition is currently in press. | No written dispatches have been printed for this subject index. | View All Editions |
| **Inquiries Pipeline** | No pending correspondence. | The post is clear. New client inquiries will appear here upon arrival. | Refresh Registry |
| **Booking Calendar** | No commissions on the call sheet. | The darkroom and atelier calendar are open for this window. | Log New Commission |
| **Media Library** | Negative tray is empty. | Drop high-resolution masters (TIFF, JPEG, AVIF) to begin developing. | Select Files |
| **404 Archive State** | Plate not found in the archive. | The requested folio has either been deaccessioned or moved to cold storage. | Return to Index |

---

### Error Notifications & Diagnostics

| Context | Notification | Resolution Guidance |
| :--- | :--- | :--- |
| **Authentication Failure** | Invalid access credentials. | Check the email and password combination. Account locks after five failed attempts. |
| **Unauthorized Action** | Insufficient clearance. | This plate or register requires administrative credentials to modify. |
| **Booking Collision / Stale Date** | The requested date is already engaged. | Another commission holds this studio date. Please select a backup date from the calendar. |
| **File Dimension or Size Error** | Master exceeds ingestion threshold. | Maximum payload is 50 MB. Acceptable formats: JPEG, PNG, WebP, AVIF, TIFF. |
| **Network / Server Interruption** | Connection to the archive severed. | Changes cached locally. Reconnecting to primary database in Uttar Pradesh. |
| **Slug Conflict** | Monograph identifier already registered. | Each monograph requires a distinct issue slug in the archive index. |

---

### Confirmation & Success States

| Context | Status Copy | Explanatory Detail |
| :--- | :--- | :--- |
| **Inquiry Dispatched** | Inquiry logged with the atelier. | We review correspondence each morning. A response will follow within 48 hours. |
| **Commission Reserved** | Commission dossier confirmed. | Reference number generated. An initial briefing document has been queued for dispatch. |
| **Monograph Published** | Issue committed to public register. | Global edge cache revalidated. Plates are now visible in the primary collection. |
| **Order Persisted (Sequencer)** | Plate sequence saved. | Negative order renumbered across all public and print folio views. |
| **Plate Deletion** | Plate deaccessioned. | Negative removed from active monograph. Source media retained in cold storage. |

## 3. Editorial Colophon Standards

Displayed across all monograph footers and the public colophon:

```text
Typeset in Editorial New and General Sans.
Plates exposed on medium format analog negative and Leica M systems.
Printed and bound under the direction of Studioza Atelier.
Issue index maintained in Uttar Pradesh, India.
All rights reserved under international archival convention.
```
